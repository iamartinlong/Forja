# 常见问题（FAQ）

## 账号与登录

**Q：频繁跳登录页 / 401？**
A：Token 有效期 15 分钟属正常设计，刷新页面会自动续期。若"频繁掉线"，检查 Redis 是否重启
（会话与队列都在 Redis）；仍异常则查看「个人资料 → 登录日志」。

**Q：忘记密码怎么办？**
A：管理员在「用户」列表编辑该账号并重置密码；本人可在「个人资料 → 安全」自助改密。

**Q：新建用户后无法登录？**
A：确认账号状态为「启用」；被禁用账号登录返回 `403 ACCOUNT_DISABLED`。

## 锻造与任务

**Q：任务卡在 RUNNING 不动？**
A：依次检查：① Worker 是否在线；② 对应炉（Furnace）是否 `healthy`；③ 炉面板最近执行记录。
炉 `unhealthy` 时先「恢复」炉，再重跑任务。

**Q：显示"炉不可达"？**
A：炉容器可能被回收（内存压力下会自动回收）。到「炉池」删除该炉记录后重新发起锻造，
系统会按项目自动重建炉容器。

**Q：三轮都失败（ESCALATED）？**
A：查看锻造页每轮的验证摘要（哪个门禁失败、失败输出），按提示补充 Spec 约束或修模板后
重新发起；不要直接改 agent 产出。

**Q：为什么改动没有出现在 master？**
A：锻造分支是隔离的，必须走「发布签核」合并（`--no-ff` + tag）。误发可用回退操作撤销合并。

## 构建与交付

**Q：构建失败（build job failure）？**
A：看流水线明细中失败步骤：常见为项目仓库自身测试/构建失败（门禁与交付构建都跑真实命令），
在本地复现修复后重新 push 再构建。

**Q：交付包在客户环境起不来？**
A：确认用 `docker load` 载入镜像 tar 后再 `docker compose up -d`；镜像 tag 以
`delivery.json` 为准（服务端已改写 compose 镜像行，不要手改）。

**Q：如何回滚到上一个版本？**
A：只认 registry 中的 `master-<sha8>` 标签镜像：改 `DEPLOY_TAG` 重新部署即可；
数据不回滚，数据问题从数据库快照恢复。

## 治理与数据

**Q：审计能导出吗？**
A：项目详情「最近动态」卡右上角有导出按钮（CSV，UTF-8 BOM 兼容 Excel）；也支持 `format=json`。
导出行为本身会记入审计。

**Q：成本是按什么统计的？**
A：按 `agent_executions`（每次 Agent 执行）聚合：执行数、输入/输出 tokens，
可选 `cost_cents`（按模型单价估算）。指标页可按项目/周期查看并导出 CSV。
未配置单价时金额为 0，只看 tokens。

**Q：模型 API Key 存在哪？**
A：AES-GCM 加密后入库，不明文落库/日志；支持双钥轮换（旧数据仍可解密）。
轮换步骤见运维 Runbook（内部文档）。

## 其他

**Q：表格数据太多找不到？**
A：列表均支持关键词检索 + 分页（每页 10/20/30/50/100，默认 10）；查询会回到第 1 页。

**Q：文档/截图能否复用？**
A：站点文档与截图随仓库发布，可自由引用；请保留来源标注。
